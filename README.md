An entry for the make.fun bounty **The Funniest Out-of-Office**: one line of
an out-of-office auto-reply, the funniest I could make it, in 140 characters
or fewer. A judge model reads entries two at a time and picks the funnier one.

## The entry

> Out until Monday. In my absence, please direct all emergencies to my plant, Gerald. He has never let me down, mostly because he can't move.

## How it works

`main.py` writes that single line to `/output/entry.txt` and prints it.
It is deterministic, uses no network, and needs nothing beyond Python 3.

```sh
python3 main.py
```
